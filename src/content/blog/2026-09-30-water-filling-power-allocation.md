N個の通信チャンネルがあって、使える電力の合計が P_total に決まっている。各チャンネルにはそれぞれ異なるノイズレベルがある。どう割り振れば、合計の情報容量が最大になるか？

この問いの答えを「注水定理（Water-Filling Theorem）」という。

## 問題を式で書く

チャンネル i のノイズ電力を σᵢ²、割り当て電力を Pᵢ とする。Shannon の公式からチャンネル i の容量は：

```
Cᵢ = log₂(1 + Pᵢ / σᵢ²)
```

合計容量を最大化したい。制約は電力の合計と非負条件：

```
maximize  Σᵢ log₂(1 + Pᵢ / σᵢ²)
subject to  Σᵢ Pᵢ = P_total,  Pᵢ ≥ 0
```

## KKT条件で解く

ラグランジアンを立てて Pᵢ で微分し、KKT 条件を整理する：

```
∂/∂Pᵢ [log₂(1 + Pᵢ/σᵢ²)] = λ
→ 1 / ((Pᵢ + σᵢ²) ln 2) = λ
→ Pᵢ + σᵢ² = μ  （定数）
```

非負条件も合わせると：

```
Pᵢ = max(μ − σᵢ², 0)
```

μ は Σ Pᵢ = P_total を満たすように決める「水位」だ。

## 水を注ぐイメージ

この式を見ると、物理的なイメージが浮かぶ。

各チャンネルに「深さ σᵢ²」の容器を並べ、水位 μ まで水を注ぐと考える。容器の底が σᵢ² で、水面が μ になる。底の位置が水位より高いチャンネルには水が入らない——つまり電力 0 で送信しない。

直感的に正しい気がするよ。ノイズが多すぎるチャンネルに電力を費やしても容量の改善は小さい。それなら条件のいいチャンネルに集中させるほうが賢い。

## 一つのパラメータで全部決まる

面白いのは、N 個のチャンネルに対して N 個の変数を最適化しているのに、解は「水位 μ」という一つのスカラーで書けることだ。

μ の決め方は次のようにする。まず全チャンネルに電力を割り当てると仮定して μ を計算し、負になったチャンネルを除外してやり直す。2〜3 回の反復で収束する。

ラグランジュ乗数 λ が「電力の辺値（追加1単位の電力が容量に与える貢献）」に対応しているので、最適解ではその貢献がすべてのアクティブチャンネルで等しくなる——これが水面が揃う理由でもある。

## 応用

OFDM（Wi-Fi、LTE、5G）では各サブキャリアが独立チャンネルに対応する。フェージングで各サブキャリアの SNR がバラつくとき、注水定理を使えば電力割り当てを最適化できる。

MIMO の固有モード伝送も同じだ。SVD で分解した固有チャンネルのゲインが σᵢ² に対応し、注水定理で各モードへの電力を決める。

実際の実装では、送信電力制御の精度や CSI フィードバックのオーバーヘッドの問題があるので、等電力割り当てで妥協することも多い。差が小さい場合も結構あるし、実装コストとのトレードオフだろうと思う。

それでも、この定理が教えてくれる「ノイズの深さに合わせて水位を揃える」という原理は、OFDM や MIMO の設計思想の根っこにある気がする。
